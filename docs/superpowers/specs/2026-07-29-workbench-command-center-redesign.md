# VisioX 工作台运营指挥台设计规格

## 目标

在现有 ChatGPT 风格全局外壳内，将工作台重构为清晰、克制且适合高频巡检的运营指挥台。页面继续使用权限范围内的真实统计接口，不增加演示数据，也不改变业务权限与轮询逻辑。

## 视觉方向

- 采用已确认的“运营指挥台”布局。
- 保留全局浅灰画布，工作台模块使用低亮度灰白表面，避免纯白卡片与背景产生刺眼反差。
- 表面层级使用 `#f3f4f6` 至 `#f7f7f8` 的中性灰，边框使用低对比度冷灰；蓝色仅用于可交互入口和主要图表数据。
- 圆角不超过 8px，阴影只用于悬浮交互，不用于静态页面分区。
- 不在面板内部继续嵌套卡片；内部状态通过分隔线、图例、数字和留白组织。
- 字号维持工作型界面密度，标题、说明、数据值形成三个清晰层级。

## 页面结构

### 页面抬头

- 左侧显示“工作台”和简短说明“训练、数据与服务运行概览”。
- 右侧显示最近统计时间和实时状态，不抢占主视觉。

### 指标总览

- 单一横向指标条展示产线、数据集、训练任务、在线服务和可用节点。
- 指标之间使用竖向分隔线，不拆成五张独立卡片。
- 数字采用等宽数字特性，单位弱化显示。

### 首屏主区

- 左侧大区域展示资产创建趋势，合并数据集和产线两类趋势，使用统一时间轴与双系列图例。
- 左侧下方展示产线运行状态，状态以横向统计项呈现，不使用嵌套状态卡片。
- 右侧展示 CPU、内存、磁盘和 GPU 使用率；遥测缺失、过期状态保留现有真实提示。

### 次级概览

- 数据集状态：环形图加状态图例与数量。
- 服务健康：健康状态、实例数和累计调用量。
- 当前活动：训练中任务、部署中服务和异常资源的简洁列表。
- 每个模块提供语义明确的查看入口，分别跳转到数据准备、模型空间或服务列表。

## 数据与交互

- 继续调用 `getWorkbenchStatistics()` 和 `getResourceStatistics()`。
- 资源统计保持 5 秒轮询，并在页面不可见时暂停。
- 首次进入时只播放图表绘制和数字轻微显现；后续轮询更新不重复播放进入动画。
- 图表悬停显示系列、时间和真实数值；交互区域保持键盘焦点和可访问名称。
- 支持 `prefers-reduced-motion`，减少动效时直接呈现最终状态。
- 保留加载、无权限、空数据、接口失败和最近成功快照提示。

## 响应式

- 宽屏：主区采用左宽右窄布局，次级概览三列。
- 中屏：资源面板移至趋势图下方，次级概览保持两列或单列。
- 窄屏：指标条改为两列或单列，图表与状态模块纵向排列，不产生横向滚动。
- 固定图表最小高度与容器比例，缩放时不改变信息顺序。

## 组件边界

- `WorkbenchView.vue` 负责数据请求、派生数据、路由入口和整体编排。
- `StatisticSummaryStrip.vue` 负责顶层指标条。
- 新增组合趋势组件，负责数据集与产线的双系列趋势。
- `PipelineStatusChart.vue`、`ResourceUsagePanel.vue` 和 `ServiceHealthPanel.vue` 只负责各自可视化，不获取数据。
- 新增当前活动摘要组件，避免将展示细节继续堆入页面文件。

## 验收标准

- 工作台与当前浅灰全局外壳视觉一致，静态模块不再使用高亮纯白表面。
- 1280px 第一屏可看到五项指标、主趋势、产线状态和资源使用率。
- 页面不存在卡片嵌套、重叠、文本溢出和横向滚动。
- 快速入口分别导航到正确业务页面。
- 所有数据来自现有权限范围统计接口，轮询、错误和空状态行为不回退。
- 前端单元测试、类型检查和生产构建通过，并完成桌面与窄屏截图验收。
