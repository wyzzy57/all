# VisiOX 融合节点迁移设计

## 目标

将当前 Windows 开发机上的 VisiOX 平台及业务数据完整迁移到
`10.10.13.20`，并将该服务器作为“平台控制面 + 边缘 GPU 计算节点”的
融合节点继续使用。迁移后入口为 `http://10.10.13.20:5174/`，现有产线、
数据集、Label Studio 标注、模型、训练记录和服务记录必须保留。

## 部署边界

- 平台服务使用 Docker Compose 运行，包括 API、任务 Worker、PostgreSQL、
  Redis、MinIO、Label Studio、MLflow、TensorBoard 和生产前端。
- 平台容器不申请 GPU。训练与推理仍由边缘执行 Worker 通过 SSH 调度
  `10.10.13.20` 上的 Docker 和 NVIDIA Runtime。
- 服务器现有的推理容器、TensorRT Engine、模型缓存、训练缓存和
  `~/.visiox` 工作目录不清理。
- 原边缘节点记录继续使用原节点 ID、地址和资源池，不重新注册节点。
- PostgreSQL 中加密的 SSH 凭据必须与
  `.local-secrets/edge_credential_master_key` 一起迁移，否则平台无法解密
  原节点凭据。

## 网络与端口

- `5174/tcp`：VisiOX 生产前端。
- `8000/tcp`：平台 API，仅由前端反向代理或局域网运维访问。
- `8081/tcp`：Label Studio 无感登录网关，避免占用服务器现有 Nginx 的
  `80/tcp`。
- `5001/tcp`、`6006/tcp`：MLflow 与 TensorBoard。
- PostgreSQL、Redis、MinIO 管理端口优先绑定到本机或 Compose 网络，避免
  不必要的局域网暴露。
- 现有推理服务端口保持不变；部署前扫描端口，发现冲突时停止迁移并报告，
  不自动改动推理服务。

## 数据迁移

采用冷快照保证跨存储一致性：

1. 停止本机 API 和会写入数据的 Worker，保留数据库与存储容器用于导出。
2. 使用 `pg_dump` 生成 PostgreSQL 逻辑备份。
3. 打包 MinIO、Label Studio、训练结果和 MLflow 数据卷。
4. 不迁移本机 15.6GB 的 Registry 数据；平台镜像在服务器重新构建，模型
   与训练产物从业务存储恢复。
5. 复制边缘凭据主密钥，但不把密钥提交到 Git。
6. 导出完成后恢复本机服务，缩短维护窗口。

## 服务器准备

- 只删除已停止的 `visiox-train-*` 临时训练容器和无引用镜像；保留
  `visiox-active-*`、推理镜像及 Engine 缓存。
- 清理前后记录 `docker ps -a`、镜像摘要和磁盘用量，用于回滚核对。
- 安装 Docker Compose v2，部署目录固定为 `/home/skyinfor/visiox`，数据
  备份保存在独立的带时间戳目录中。
- 以当前工作树制作源码包，包含尚未提交的大模型训练功能，但排除 `.git`、
  `.env`、本地密钥、依赖缓存和构建产物。

## 恢复与融合节点处理

1. 在服务器创建新 Compose 数据卷并恢复 PostgreSQL 与文件数据。
2. 写入服务器专用 `.env`，公共 URL 全部指向 `10.10.13.20`。
3. 构建并启动平台服务，执行数据库迁移。
4. 从迁移后的节点记录读取原 SSH 凭据，由边缘 Worker 从容器内通过
   `10.10.13.20:22` 回连宿主机。
5. 对原有服务逐个核对数据库容器 ID、实际容器和健康端点。容器存在但已
   停止时仅恢复明确标记为运行中的服务；无法匹配时保留记录并显示可诊断
   错误，不创建重复容器。

## 验收

- `http://10.10.13.20:5174/` 可访问，刷新任意前端路由不返回 404。
- 健康检查通过，数据库迁移版本正确，所有 Compose 服务保持稳定运行。
- 产线、数据集、标注项目、训练记录、模型和服务数量与迁移前一致。
- Label Studio 可由 VisiOX 无感跳转，MLflow 与 TensorBoard 链接可访问。
- 平台能探测融合节点 GPU；提交一个最小训练任务后由服务器 GPU 执行。
- 选择一个现有推理服务完成健康检查和图片 HTTP 推理。

## 回滚

- 迁移期间不删除本机数据；服务器恢复失败时停止新 Compose 项目并恢复
  迁移前 Docker 状态。
- 所有远端清理都限制在已停止的临时训练容器和无引用镜像，不删除数据卷、
  推理容器或 `~/.visiox`。
- 在服务器验收完成前，本机仍是可回退的原平台。
