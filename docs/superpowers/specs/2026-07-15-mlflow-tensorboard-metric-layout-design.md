# VisioX 训练指标分组与训练对比设计

## 目标

将当前“所有训练指标共用一张图和一个纵坐标”的展示方式，调整为 TensorBoard 风格的单次训练指标卡片，并增加 MLflow 风格的多次训练对比。

MLflow 与 TensorBoard 继续负责训练数据采集和存储。VisioX 原生页面通过现有观测 API 展示指标，不嵌入第三方页面，也不直接读取第三方前端状态。

## 设计依据

TensorBoard 以标量 tag 组织数据。每个标量图对应一个 tag，并可在同一图中比较包含该 tag 的多个 run。tag 可使用路径式命名形成分组。其主要交互包括平滑、缩放、悬浮读数、固定卡片和下载。

MLflow 以 experiment、run 和 metric 为核心。单个 metric 按 step 和 timestamp 保存完整历史；训练对比时，应在同一 metric 上叠加多个 run，而不是将不同量纲的 metric 放在同一纵轴。

VisioX 采用混合方案：

- 单次训练观察采用 TensorBoard 风格的指标卡片网格。
- 多次训练比较采用 MLflow 风格的 run 选择和同指标曲线叠加。

## 单次训练指标

### 指标分组

页面根据规范化后的指标名分为：

1. 损失
   - `box_loss`：`train.box_loss` 与 `val.box_loss`
   - `cls_loss`：`train.cls_loss` 与 `val.cls_loss`
   - `dfl_loss`：`train.dfl_loss` 与 `val.dfl_loss`
2. 模型质量
   - `metrics.precision`
   - `metrics.recall`
   - `metrics.map50`
   - `metrics.map50_95`
3. 优化过程
   - `learning_rate`
4. 其他标量
   - 后端返回但未进入内置分组的指标，每个指标单独生成卡片。

### 纵坐标规则

- Precision、Recall、mAP 的纵轴固定为 `0～1`。
- Learning Rate 使用独立图表和科学计数法。
- Loss 使用自动范围，不与质量指标共用纵轴。
- 百分比指标固定为 `0～100`。
- MB、GB、秒、样本数等不同单位分别建图。
- 未识别单位的指标只与自身序列共享纵轴。

### 指标别名

采集源可能同时返回 Ultralytics 框指标的带后缀名称。展示前统一规范化：

```text
metrics.precisionb -> metrics.precision
metrics.recallb -> metrics.recall
metrics.map50b -> metrics.map50
metrics.map50_95b -> metrics.map50_95
```

同一规范名存在多个来源时，按照 VisioX telemetry、MLflow、TensorBoard 的既有聚合优先级保留一份序列，不能生成重复卡片。

### 卡片交互

- 默认使用两列响应式网格，窄屏自动变为一列。
- 卡片显示名称、最新值、最优值和曲线。
- 支持悬浮读数、图例开关、局部缩放、恢复缩放和下载图片。
- 提供全局平滑控制；平滑只影响显示，不修改原始值和悬浮读数。
- 图表容器使用 `ResizeObserver` 触发 ECharts `resize()`，修复首次进入页签或侧栏尺寸变化后的布局问题。
- 空序列不生成卡片；数据源不可用时保留现有可用性提示。

## 多次训练对比

指标页增加“单次训练”和“训练对比”两个视图。

训练对比包含：

- 从当前产线或全部可见训练中选择 `2～5` 个 run。
- 选择一个规范化指标。
- 同一图中每条曲线代表一个 run，并使用相同纵轴规则。
- 展示每个 run 的最终值、最优值、最优值对应 step、状态和关键参数。
- 不允许在同一图中选择多个不同指标。
- 某个 run 缺少所选指标时，在比较表中显示“无数据”，其余 run 继续展示。

第一版复用现有逐任务观测 API 并并发读取选中 run。暂不新增批量比较后端接口；当训练记录规模导致请求数量成为瓶颈时，再增加批量查询端点。

## 组件边界

### 指标目录模块

新增纯函数模块负责：

- 指标名称规范化；
- 标签与分组映射；
- 单位和纵轴策略；
- train/val 语义配对；
- 最新值和最优值计算。

该模块不依赖 Vue 或 ECharts，便于单元测试。

### 图表组件

现有 `MetricLineChart` 扩展为接受：

- 明确的图表标题；
- 一个语义指标及其一条或多条可比较序列；
- 纵轴范围、单位与格式化策略；
- 平滑系数；
- 紧凑卡片尺寸或对比视图尺寸。

组件不再接收并混画任意量纲的指标集合。

### 页面组件

`TrainingVisualizationView` 负责：

- 加载所选任务的真实标量；
- 将数据交给指标目录模块分组；
- 渲染单次训练卡片；
- 管理对比 run、对比指标和并发请求；
- 保持运行中任务的轮询以及任务切换时的陈旧响应保护。

## 兼容性与错误处理

- 旧训练缺少部分指标时只隐藏对应卡片，不生成模拟数据。
- 运行中任务继续按当前间隔轮询，新数据更新已有图表实例。
- MLflow 或 TensorBoard 单源不可用时，继续显示其他来源已聚合的数据。
- run 切换和对比选择变化时，旧请求返回结果不得覆盖当前选择。
- 现有 TensorBoard 高级入口、训练结果图和资源页保持不变。

## 测试

- 指标目录单元测试覆盖别名规范化、分组、train/val 配对、纵轴规则和最优值计算。
- 图表组件测试覆盖固定范围、自动范围、科学计数法、平滑和 ResizeObserver 生命周期。
- 页面测试覆盖指标卡片分组、重复别名消除、空指标隐藏和运行中刷新。
- 对比测试覆盖 2～5 个 run、缺失指标、任务切换和陈旧响应。
- 浏览器验收覆盖桌面与窄屏布局，确认卡片不重叠、纵轴单位正确且首次打开无需刷新。

## 完成标准

- 不同量纲的指标不再共享纵坐标。
- 单次训练页面可以同时快速浏览 Loss、质量指标和 Learning Rate。
- train/val 只在相同语义指标卡片中配对。
- 用户可以选择多个训练 run，并在同一指标上进行公平比较。
- 页面首次进入、切换页签和侧栏尺寸变化时图表尺寸正确。
- 所有展示值来自真实观测数据，不补造历史曲线。
