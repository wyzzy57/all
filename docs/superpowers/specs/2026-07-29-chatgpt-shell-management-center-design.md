# VisiOX ChatGPT 风格应用外壳与管理中心设计

**日期：** 2026-07-29
**状态：** 已确认，进入实现

## 目标

在不改变现有业务页面、API、路由权限和资源数据的前提下，重做登录后应用外壳：使用与 ChatGPT Web 接近的浅灰背景和融合式左侧栏，将 VisiOX 品牌放入侧栏顶部，并将账户与管理员功能收纳到圆角账户菜单和独立管理中心窗口中。

## 已确认的视觉与交互

- 应用画布使用暖中性的浅灰色，侧栏使用略深一档的浅灰色，业务卡片保持白色。
- 删除独立顶部栏及其分隔线，VisiOX 标志进入左侧栏顶部。
- 侧栏导航不再使用白色分组卡片；菜单直接融入灰色侧栏。
- 当前菜单项使用浅灰底和深色文字，不使用浅蓝底或左侧蓝色竖线。
- 侧栏展开宽度为 224px，收起宽度为 68px；收起按钮只在侧栏悬停、聚焦或触摸设备上显示。
- 底部账户入口与侧栏融合；点击后在入口上方显示带圆角、边框和柔和阴影的账户菜单。
- 账户设置、平台总览、用户管理、用户分组、资源授权、审计日志、节点与资源不再替换主业务页面，而是在独立管理中心窗口中展示。
- 管理中心窗口左侧是功能目录，右侧复用现有功能页面；管理员目录仅对管理员显示。
- 原 `/account`、`/admin/*` 路由继续保留，确保深链接和现有权限测试不失效。

## 组件边界

### `App.vue`

负责全局侧栏、移动端覆盖层、账户菜单和管理中心的打开状态，不承载用户管理业务逻辑。

### `UserAccountMenu.vue`

负责身份摘要、菜单展示和退出登录。选择管理功能时发出 `open-management` 事件，不直接改变当前业务路由。

### `ManagementCenterDialog.vue`

负责管理窗口结构、目录切换、管理员可见性和焦点/关闭行为。右侧内容通过异步组件复用既有视图。

### 既有视图

`AccountView`、`AdminOverviewView`、`UserManagementView`、`GroupManagementView`、`AuthorizationView`、`AuditLogView`、`NodeManagementView` 保持原有 API 和业务行为，只在管理窗口的滚动内容区中呈现。

## 响应式与可访问性

- 桌面管理窗口最大宽度 1080px、高度不超过视口减 40px。
- 窄屏管理窗口占据视口，目录可以横向滚动或收窄，不产生整页横向溢出。
- 所有图标按钮有 `aria-label`，Esc 可关闭窗口，键盘焦点可见。
- 侧栏移动端展开时提供可点击遮罩，避免内容误触。
- 动画只使用 `opacity` 和 `transform`，并尊重 `prefers-reduced-motion`。

## 验收条件

1. 主界面不存在独立全局顶部栏，VisiOX 标志位于侧栏顶部。
2. 当前导航项是浅灰色，不出现蓝色选中背景或蓝色左边线。
3. 账户菜单圆角悬浮在账户入口上方。
4. 点击账户或管理员功能会打开管理中心，并切换到正确目录，不离开当前业务页面。
5. 普通用户看不到管理员目录。
6. 现有路由、账户更新、密码修改、退出登录和管理员业务功能继续通过测试。
7. 720px 以下侧栏默认收起，可作为覆盖层展开并通过遮罩关闭。
